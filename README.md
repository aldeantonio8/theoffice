# The Office

An interactive 3D portfolio experience built as a virtual office.

## Vision

Instead of navigating a traditional website, visitors enter a virtual office and explore departments such as Reception, Human Resources, Operations, Procurement and the Director's Office.

## Stack

- Next.js
- React
- TypeScript
- Three.js
- React Three Fiber
- Drei

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.
